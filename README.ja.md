## プラットフォームの概要

**skills.rest** は、AIエージェントおよび自動コーディングアシスタントのためのオープンなスキル登録・検索プラットフォームです。750,000件以上の審査・検証済み実行可能スキルパッケージ（Skill Packages）をインデックス化しており、AIエージェントの手続き的知識、専門領域のワークフロー、実行能力を拡張します。

登録されているすべてのスキルはオープンな標準仕様（標準化された `SKILL.md` 指示書および任意の実行スクリプトや依存関係リスト）に準拠しています。本レジストリは完全無料かつ継続的に更新され、大規模言語モデルと決定論的なエンジニアリングタスク実行との間を架橋します。

## skills.rest で利用者が行えること

日々の開発環境を強化したいエンジニア、自律型マルチエージェントを設計するアーキテクト、独自機能を公開したいオープンソース開発者など、あらゆる利用者のために充実した探索モジュールとツールを提供しています。

### 1. スキルカタログの横断検索と多次元フィルタリング
- **キーワード・自然言語検索**: タスクの自然言語解説、ツール名、技術分野（例: `pdf抽出`、`テスト駆動開発`、`データベース移行`）を入力して目的のスキルを即座に特定できます。
- **多次元フィルタリング機能（`/explore`）**:
  - **カテゴリ分類**: 10の専門領域からワークフローに合った分類を選択。
  - **発行元種別**: 認証された専門組織による **Official** スキルと、独立した開発者による **Community** オープンソーススキルをワンクリックで切り替え。
  - **複雑度レベル**: スキルの難易度（**Basic 基礎**、**Intermediate 中級**、**Advanced 専門レベル**）に応じて絞り込みが可能。
- **快適な連続ブラウジング**: スクロール位置の記憶機能を備えており、スキル詳細ページから一覧に戻った際も閲覧位置をシームレスに維持します。

### 2. スキル仕様書とシステム要件の確認
各スキルには専用の詳細ページ（`/skill/[slug]`）が用意されており、安全な導入と実行に必要な情報を確認できます:
- **システムドキュメント**: 解決する具体的な課題、主要機能リスト、対応フレームワーク、実務上のユースケースを明記。
- **依存関係と前提条件**: 実行に必要なコマンドラインツール、ランタイムバイナリ、環境設定、コンパニオンパッケージを透明性高く表示。
- **開発者情報とコミュニティ指標**: 作者の認証バッジ、リポジトリのStar数、フォーク数、公式ソースコードへの直接リンクを表示。
- **インタラクティブFAQ**: インストール手順、互換性の境界条件、活用パターンに関するよくある質問と回答を提供。
- **関連スキルの推薦**: 同じ機能領域や関連技術スタックのスキルを横断的に提案。

### 3. ワンクリック端末インストールと構造化プロンプトの取得
手作業による環境構築の手間を省くため、カードおよび詳細ページから実行コマンドを直接取得できます:
- **主要パッケージマネージャーに対応**: 開発環境に合わせて `npx`、`pnpm dlx`、`bunx` を切り替えてコマンドをコピー可能:
  ```bash
  npx skills add <リポジトリURL> --skill <スキル名>
  ```
- **エージェント向け構造化プロンプト**: AIアシスタントのチャット画面にそのまま貼り付けられる構造化プロンプトを提供。エージェントが自律的にスキルを検査・取得・適用します。

### 4. スイートの探索と一括インストールコマンド生成（`/best-skills` および `/repo/...`）
複数のスキルが連携して動作するプロジェクト向けに、リポジトリスイート機能を提供しています:
- **Best Skills ハブ（`/best-skills`）**: デザインシステム、アーキテクチャ刷新、データ解析など、コミュニティで高い評価を得ている総合スイートを一覧表示。
- **リポジトリ専用ページ（`/repo/[owner]/[name]`）**:
  - **全スキルの一括インストール**: リポジトリ内の全スキルをグローバルに導入するコマンドを一括生成（`--all -g -y`）。
  - **カスタム複数選択モード**: チェックボックスで必要なスキルのみを選択し、画面下部のフローティングバーから組み合わされたインストールコマンドを取得。
  - **エージェントガイドの抽出**: 既存の設定ファイルを上書きせず、安全にガイドラインを統合するためのプロンプトを抽出。

### 5. AIエージェントへのオンデマンド自律検索機能の付与（`/skills-search-cli`）
Web画面での手動検索に加え、AIエージェント自身が必要に応じてスキルを発見・導入できるようにします:
- **ローカル検索ツールの導入**: 軽量なヘルパーツール（`skill-discovery`）をローカルのエージェント環境に導入。未知のタスクに直面した際、エージェントがレジストリAPIを照会し、最適な候補を提示してユーザーの承認を得た上で自動導入します。
- **設定不要のユニバーサルルール**: 共通の検索プロトコル指示文をワークスペース設定（`AGENTS.md` やシステムプロンプトなど）に記述するだけで、あらゆる標準準拠エージェントに即座に検索能力を付与できます。

### 6. 認証組織・開発者ディレクトリの閲覧（`/companies`）
- **技術組織のカタログ**: 認証された技術機関、オープンソース開発組織、専門チームを一覧表示。
- **エコシステム別の分類**: クラウドインフラ、人工知能・モデルランタイム、開発者ツール、セキュリティ、データ基盤などの領域ごとに組織を整理。
- **組織プロフィールと能力チャート**: 各組織が公開している全スキルや、注力分野を幾何学的に表現したSVG能力分布図を閲覧可能。

### 7. 自作スキルの登録申請（`/contribute`）
- **オープンソース貢献ポータル**: 開発者やメンテナは、標準仕様に準拠した公開GitリポジトリのURLを入力するだけで登録を申請できます。
- **自動セキュリティスキャンと審査**: 申請されたリポジトリは自動検査パイプラインに入り、`SKILL.md` の規格準拠、実行スクリプトの安全性、依存関係の健全性を確認した上でインデックスに登録されます。

## カバーする10の専門領域

レジストリに登録されたスキルは、以下の10のワークフロー領域に体系化されています:

| 分類 | 代表的なユースケースと能力 |
|---|---|
| **ソフトウェアエンジニアリング** | コード生成、アーキテクチャ移行、自動リファクタリング、TDDワークフロー、CI/CDパイプライン自動化、デバッグ。 |
| **データ＆アナリティクス** | 構造化データ抽出（SQL/CSV/JSON）、表解析、データベース最適化、BIレポート生成。 |
| **デザイン＆クリエイティブ** | デザインシステムの構築、SVGベクター生成、レスポンシブUI監査、タイポグラフィ調整、アニメーション実装。 |
| **コンテンツ＆コミュニケーション** | 技術文書作成、更新履歴の自動生成、ドキュメント同期、構造化原稿の執筆。 |
| **プロダクト＆マネジメント** | ユーザーストーリー作成、バックログ整理、スプリントリリースノート生成、ロードマップ策定。 |
| **教育＆リサーチ** | 学術論文の要約、LaTeX数式変換、文献引用フォーマット検証、学習カリキュラムの編成。 |
| **ファイナンス＆アカウンティング** | 財務スプレッドシートのモデリング、請求書解析、予算照合、取引監査。 |
| **法務＆コンプライアンス** | 契約条項の相互参照、ライセンス適合性スキャン、規制要件チェックリストの作成。 |
| **マーケティング＆セールス** | 構造化メタデータ作成、アウトリーチ文章作成、競合製品の機能比較分析。 |
| **パーソナル＆生産性** | 日常業務の自動化、第二の脳（ナレッジベース）の連携、タスク管理、定期ルーティン実行。 |

## セキュリティ、プライバシー、実行原則

- **完全なローカル実行**: すべてのスキルはユーザーのローカル環境または指定された安全なエージェントサンドボックス内でのみ実行されます。プラットフォーム側でユーザーコードを実行することはありません。
- **明示的なユーザー承認**: インストールコマンドや自動ツールは、端末スクリプトを実行する前に必ずユーザーの明示的な確認を求めます。
- **自動セキュリティスクリーニング**: 登録されるスキルは、悪意あるコマンドの呼び出しや未検証の外部スクリプトを含んでいないか多層的に自動スキャンされます。
- **アカウント不要**: 会員登録やアカウント作成、独自の有料プランへの加入なしに、全機能を自由に利用できます。

## 利用開始の流れ

1. [skills.rest](https://skills.rest) にアクセスし、タスクのキーワードを入力するかカテゴリからスキルを探します。
2. 目的のスキルを選択し、要件とシステム仕様を確認します。
3. インストールコマンドまたは構造化プロンプトをコピーして、エージェントの環境で実行します。
4. （任意）[Skills Search CLI ガイド](https://skills.rest/skills-search-cli) を参照し、エージェントが自律的にスキルを発見できるように設定します。
